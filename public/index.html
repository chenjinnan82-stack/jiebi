Your paper stays yours.

The assistant can add editable lines and words, revise only its untouched work, or stop. Your edits are protected. A late response cannot replace a newer draft.

Each paper has a separate conversation. The extension does not read the webpage beneath it.

Install & connect
  1. Unzip the download.
  2. Open Chrome’s extension manager, turn on Developer mode, then choose Load unpacked and select the extension folder.
  3. Pin 接笔. Open an ordinary webpage to find its paper roll.
  4. For now, run the local bridge using the source instructions. Hosted judging access is not yet available.
Keyboard & gestures

The roll supports Enter and the up/down arrows. Focus the bottom edge and use left/right to switch writing and drawing. Command/Ctrl+Enter hands over; Escape saves without sending. The corner opens the paper stack. Reduced motion is supported.

What is still unfinished?

The webpage curtain needs final verification in the installed Chrome extension. Hosted review access and the continuous demonstration are pending.

Model expression remains uneven. It may leave an incomplete drawing or misunderstand a visual edit. Invalid responses are rejected as a whole. A reply usually takes several seconds; the roll’s animation is a status signal, not a progress meter.

Privacy & model

Papers are saved in extension storage. Only an intentional handoff sends the current paper and limited exchange history to the selected service.

The competition route uses NVIDIA Nemotron-3.5-Super-VL through Nebius Token Factory. The optional Grok Bot adapter is experimental and has not completed live validation. No private assistant memories are connected.
